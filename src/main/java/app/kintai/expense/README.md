# expense：交通費・経費　担当：山川

Google フォームの回答シートから、「承認」が TRUE の金額を社員番号ごと・月ごとに合計する。

| ファイル | 中身 |
|---|---|
| ExpenseTotals | 回答シートの行から合計を出す（見出しの名前で列を探す） |
| ExpenseService | 「設定」に登録した回答シートを読む |

## やること
- [ ] 交通費・経費フォームを用意する（既存のフォームでもよい）。質問に「社員番号」「利用日」「金額」を入れる
- [ ] 回答シートに「承認」列を足し、山本さんがチェックする運用を決める
- [ ] 画面「設定」に、フォームと回答シートのURLを登録する
- [ ] 承認をシステムの画面でできるようにするか決める（するなら承認の表を作り、ここで読む）


## 担当内容（山川さん）
- 上の「やること」を上から順に進める
- このフォルダのファイルを変えたら、対応するテストも足す
- 他の人の担当フォルダを変えたいときは、自分で直さずに担当者へ伝える（Issue か Pull Request に名前を書く）
